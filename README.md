# Pizza Frenzy Deluxe (C++ port)

A C++ decompilation of Pizza Frenzy Deluxe 1.0 (Sprout Games, 2006; PopCap re-release), written
from the original binary.

You must include your own game files to the bin folder.

## Building

Open `PizzaFrenzy.slnx` in Visual Studio 2026 (v145 toolset, platform x86) and pick:

- **Release** to build the way the original was built. Output goes to `Bin\`.
- **Debug** for work. Output goes to `Bin\Debug\`.
